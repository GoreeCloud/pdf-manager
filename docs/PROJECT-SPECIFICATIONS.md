# Project Specifications — GoreeCloud PDF Manager

- Repository: `GoreeCloud/pdf-manager`
- Product: GoreeCloud PDF Manager
- Lifecycle: Forge
- Version: `0.1.0-dev`

## Purpose

PDF Manager provides a coherent GoreeCloud interface and service boundary for everyday and advanced PDF processing without requiring core workflows to be routed through a third-party file service.

## Required outcomes

1. Maintain a legally clear open-source source boundary.
2. Deliver major PDF workflows through a polished Glaze interface.
3. Preserve useful mature upstream processing where licensing and GoreeCloud standards permit.
4. Use privacy-preserving defaults with optional telemetry disabled.
5. Treat hostile document input as a high-risk security boundary.
6. Meet keyboard, screen-reader, contrast, reduced-motion, responsive, and touch-target requirements.
7. Maintain exact source provenance, reviewable branches, CI, feature records, and changelogs.
8. Never manufacture Identity, Privacy Shield, Wardveil, Everkeep, Mesh, Policy, Observability, or Manager state in presentation code.

## Current direct workflows

Merge, split, rotate, optimize/compress, and image extraction are directly wired in the GoreeCloud workbench.

## Current non-claims

This candidate does not claim Anchor qualification, production deployment acceptance, end-to-end encryption, complete Glaze consumer acceptance, or accepted GoreeCloud platform-system integrations.
