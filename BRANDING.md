# Branding

## Product identity

- **Canonical full product name:** GoreeCloud PDF Manager
- **Approved short application label:** PDF Manager
- **Brand relationship:** Prefixed GoreeCloud family product
- **Repository:** `GoreeCloud/pdf-manager`
- **Lifecycle:** Lab
- **Implementation status:** Exploratory native foundation

The full canonical name should be used in repository documentation, product records, release material, provenance, About/legal surfaces, and other contexts where GoreeCloud ownership matters.

When an installable application exists, operating-system launchers, app drawers, installed-app lists, and equivalent compact runtime surfaces should use **PDF Manager**, not **GoreeCloud PDF Manager**.

## Visual identity

No PDF Manager-specific production icon, logo, wordmark, or application artwork is verified in this repository.

Until approved product-specific assets exist:

- Do not invent a production logo or icon.
- Do not reuse third-party PDF product trade dress.
- Use GoreeCloud branding only through approved shared assets and Glaze UI conventions.
- Keep document/workspace content visually primary; decorative effects must not reduce document readability.

## Glaze UI

Glaze UI is the planned GoreeCloud interface foundation. No Glaze UI runtime implementation or consumer-acceptance evidence exists in this repository.

Implementation must use the then-current applicable Stable Glaze UI contract and must preserve accessibility, reduced-motion, reduced-transparency, increased-contrast, keyboard, and responsive behavior required by GoreeCloud governance.

## Naming boundaries

- Product documentation: **GoreeCloud PDF Manager**
- Short installed-app label: **PDF Manager**
- Repository identifier: `pdf-manager`
- Machine-readable component identifier: `goreecloud-pdf-manager`

Technical identifiers may use lowercase GoreeCloud namespaces where required by their platform syntax.

## Brand validation

Branding is not considered production-accepted until the implemented application has approved assets, correct naming across supported platforms, accessible presentation, Glaze UI acceptance, and representative runtime evidence.
